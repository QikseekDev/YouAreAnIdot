# YouAreAnIdiot

A recreation of the classic **"You Are An Idiot"** web experience, rebuilt with plain HTML, CSS and JavaScript.

The goal is to recreate the original behavior as closely as possible while keeping the project simple and easy to run.

> **Warning:** This project uses popup windows, autoplaying audio and other browser features that can behave differently depending on the browser.

## Live Demo

The project is hosted at:

**https://youare.qzz.io**

## Features

* Windows 95-style UI
* Real browser popup windows
* Popup permission testing
* Audio autoplay detection
* Audio unlocking through user interaction
* Mouse, touch, pen and keyboard input
* Cross-window communication using `postMessage()`
* Window resizing through `window.resizeTo()`
* No frameworks or build system required

## Browser Behavior

Browser behavior is different depending on the browser. This table is based on testing the project.

| Browser | Behavior | Notes |
| --- | --- | --- |
| **Google Chrome** | Popup windows open very quickly. Large numbers of popup windows can cause movement to become laggy. | Recent Chromium versions may allow the audio to play without requiring a separate autoplay unlock. |
| **Brave** | Popup windows work after allowing popups. Large numbers of popup windows can cause movement to become laggy. | Allowing popups may require clicking **OK** or refreshing the page. Autoplay behavior can vary depending on browser version and settings. |
| **Firefox** | Autoplay, popup detection and popup spam work. Easier to close with **Alt+F4**. | Close the popups quickly. Firefox can sometimes open new ones even after they appear to be fully closed. Using **Windows taskbar → right-click Firefox → Close all windows** can cause new popup windows to open again shortly afterward, even with only one popup window open. |
| **Microsoft Edge** | Very similar to Chrome. Popup windows can open very quickly, and movement may become laggy when many are active. | After enabling popups, click **OK** or refresh the page. |
| **Opera** | Currently broken. Some popup windows can open fullscreen, which ruins the popup behavior. | Chromium-based. Autoplay and popup behavior may vary between versions. |
| **Safari** | Not fully tested yet. | WebKit-based browser; popup and autoplay behavior may differ from Chromium and Firefox. |
| **Vivaldi** | Not fully tested yet. | Chromium-based browser. |
| **Other Chromium browsers** | Behavior is expected to be similar to Chrome, but popup and autoplay policies may differ. | Large numbers of popup windows may cause movement lag. |

### Popup Spam and Performance

The project intentionally opens and moves multiple browser popup windows.

Chromium-based browsers such as Chrome and Brave can allow popup windows to open very quickly. When a large number of windows are active at once, the movement logic may begin to lag because the browser has to update many windows simultaneously.

This is more noticeable when popup spam gets particularly large.

More browser testing will be added later.

## Running

There is no build process. It's just a static website.

You can run it with any HTTP server. For example:

```bash
python -m http.server 8000

Then open:

http://localhost:8000

Using a local server is recommended instead of opening index.html directly.

Popup Flow

The main flow starts in index.html.

index.html
    |
    +-- Check autoplay
    |
    +-- Test popup permission
    |     |
    |     +-- test.html?id=0
    |     +-- test.html?id=1
    |     +-- test.html?id=2
    |
    +-- Open popup.html
            |
            +-- Main popup

The three test windows are used to check whether the browser is allowing the popups required by the project.

popup.html can also communicate with index.html using postMessage() and request a window resize when needed.
